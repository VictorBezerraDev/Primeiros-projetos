# 📚 Primeiros Projetos

Repositório que reúne os **primeiros exercícios e práticas** desenvolvidos durante o meu percurso de aprendizagem em programação. Serve como registo da minha evolução e como portefólio inicial.

---

## 📋 Sobre o repositório

Aqui estão guardados os exercícios resolvidos, as práticas realizadas ao longo do curso e o respetivo certificado de conclusão. Cada pasta agrupa um tipo de trabalho, para facilitar a consulta.

## 📁 Estrutura

```
Primeiros-projetos/
├── Praticas/                      # Práticas desenvolvidas ao longo da formação
└── exercicio/                     # Exercícios de apoio e resolução de problemas

```

| Item | Descrição |
| ---- | --------- |
| `Praticas/` | Projetos práticos para aplicar os conceitos aprendidos |
| `exercicio/` | Exercícios para treinar a lógica e a sintaxe |

## 🚀 Como usar

1. **Clonar** o repositório:
   ```bash
   git clone https://github.com/VictorBezerraDev/Primeiros-projetos.git
   ```
2. **Entrar** na pasta:
   ```bash
   cd Primeiros-projetos
   ```
3. Navegar até à pasta pretendida (`Praticas` ou `exercicio`) e abrir os ficheiros no navegador ou no editor de código.
